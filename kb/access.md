# Account access

## Password reset link
Password reset links expire after 30 minutes. Request a new link from the sign-in page using Forgot password. Open only the newest email. If it does not arrive, check spam and verify the account email. Support never asks for your password or a one-time code.

## Invite a teammate
Workspace admins can invite a teammate from Settings > People > Invite. Confirm the email address and select the appropriate role. If an invitation expired, the admin can resend it from the People screen.
