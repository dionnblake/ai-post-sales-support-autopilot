# Getting started

## Create a project template
Create a project, add its standard task list, and choose Save as template from the project menu. Workspace admins can make a template available to the whole workspace. New projects created from a template are independent copies.

## Assign a task due date
Open the task, select Due date, and choose a date and time. The task view uses your profile time zone. Check Profile > Preferences > Time zone if dates look incorrect. Changing your profile time zone does not change the underlying stored deadline.
