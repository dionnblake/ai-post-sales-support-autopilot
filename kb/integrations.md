# Integrations and exports

## Reconnect Slack notifications
If Slack notifications stop, open Settings > Integrations > Slack and select Reconnect. Confirm the destination channel and send a test notification. Only a workspace admin can reconnect the integration. If the test fails, collect the error message and route to Technical Support.

## Export tasks to CSV
Open the project task list and select Export > CSV. The export includes tasks visible to your role. Large exports may take several minutes. If an export fails twice, send the project ID and approximate task count to Technical Support; do not attach confidential task contents.
